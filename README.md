# Digital Clock

A lightweight browser-based digital clock built with HTML, CSS and JavaScript.

## Features

- Real-time digital clock
- Automatic time updates
- Clean browser-based interface
- No external dependencies

## Technologies

- HTML5
- CSS3
- JavaScript

## Run Locally

Clone the repository or download the files, then open:

in a web browser.

## Purpose

This project demonstrates JavaScript application logic, DOM interaction, event handling and frontend interface development.
